THE INNOVATION

Big Knowledge. Tiny Hardware.

An ultra-minimal approach to offline digital learning.

🔧

Ultra-Minimal Hardware

Built using only an ESP32 and a 256-GB microSD card, eliminating the need for a Linux-based computer or complex server setup.

💰

Approximately $10–11

An ultra-low-cost and low-power educational technology solution designed to make offline learning more accessible.

🚫🌐

No Internet Required

No external router, Internet connection, or mobile data is required for learners to access the library.

🐧🚫

No Linux Required

No Linux computer, complex server, or complicated software installation is needed for learners.

📶

Classroom Ready

Approximately 30 metres of Wi-Fi range and support for approximately 20–40 simultaneous students based on testing.

📱

One-Click Access

Students can use existing phones, tablets, or laptops through a standard web browser with no dedicated app.
